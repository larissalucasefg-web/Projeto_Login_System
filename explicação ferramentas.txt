Node.JS permite usar JS fora do navegador (Fogão)
npm é o gerenciador de pacotes do node.JS (Panelas)
Docker cria um ambiente padronizado para rodar o sistema, atráves dele fazemos um gerenciamento do nosso banco de dados (Caixa térmica com as marmitas)
npm init -m(y) gera o arquivo package.json
npm install express cria as nossas rotas, com o servidor HTTP(endereço de sites)
bcryptjs faz a criptografia das senhas dentro do nosso JS, a parte de segurança
jsonwebtoken gera um token da sessão de login
dotenv conecta com o nosso banco de dados
mongoose é o banco de dados
npm install --save-dev nodemon reponsável por reiniciar o servidor quando faz alterações no código
